# Adrian Johnson

**Identity & Access Management and Windows infrastructure engineer, 20+ years.**
Seattle, WA · Available for consulting and contract engagements.

I design, fix and automate identity infrastructure: Active Directory, Entra ID, federation (SAML / OIDC), PKI and hybrid Exchange. I've done this work across higher education, enterprise and media/entertainment. Most of my automation is PowerShell, with Python, Terraform and Ansible where they fit.

## What I work on

- **Active Directory & Entra ID:** security audits, hardening, hybrid sync, domain migrations, privileged access
- **Federation & SSO:** SAML, OIDC, CAS, Shibboleth, Keycloak, Okta, PingFederate integrations and troubleshooting
- **PKI & certificates:** AD CS design and consolidation, EJBCA, Keyfactor, Venafi, Sectigo, certificate lifecycle automation
- **Microsoft 365:** hybrid Exchange, Conditional Access, security testing with Maester
- **Automation:** PowerShell modules, infrastructure as code, repeatable runbooks
